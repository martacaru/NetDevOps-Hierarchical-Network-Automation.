# NetDevOps: Automatización de Redes Jerárquicas Dual-Stack
Proyecto integrador de automatización de redes IPv4/IPv6 con Python, Netmiko y GNS3.



Este repositorio contiene el proyecto integrador de automatización de red utilizando una topología jerárquica con soporte IPv4/IPv6 en GNS3.

## 🛠️ Tecnologías y Herramientas
- **Lenguaje:** Python 3.12
- **Librerías:** Netmiko, PyYAML
- **Simulador:** GNS3 / Ciscolive
- **Formatos:** YAML para configuración declarativa

## 📂 Archivos del repositorio
- `Script_de_Automatizacion.py`: Script en Python para la aplicación de configuraciones de red.
- `config_red.yaml`: Archivo de variables con direccionamiento IP y parámetros de red.
- `Tesis_NetDevOps.pdf`: Documento completo con la memoria técnica del proyecto.
